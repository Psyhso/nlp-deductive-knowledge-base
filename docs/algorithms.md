# Алгоритмы логического вывода

## Полунаивное вычисление

Профильный движок хранит известные факты `K` и множество новых фактов предыдущего раунда `Δ`. Новое применение правила должно использовать хотя бы одну посылку из `Δ`. Чтобы не проверять одни сочетания несколько раз, варианты разбиваются по первой новой посылке: до неё используются старые факты `K \ Δ`, в ней — `Δ`, после неё — полное `K`.

Результаты раунда накапливаются отдельно. Из них удаляются уже известные факты, оставшиеся становятся следующей `Δ`. Пустая дельта означает неподвижную точку.

Безопасные правила не создают новых констант или функциональных термов. Возможных ground-фактов конечное число, а множество известных фактов только растёт. Поэтому вычисление заканчивается. Отрицательные литералы здесь являются явно подписанными фактами, без отрицания по отсутствию и без полного классического следования.

Наивный алгоритм повторяет все применения правил на каждом раунде. В тестах используется независимый наивный эталон для сверки результата полунаивного вывода.

## BFS

Вспомогательный обход применяется к положительным бинарным отношениям с явно заданной семантикой замыкания. Он находит достижимость и кратчайшие цепочки-объяснения. Цикл считают ошибкой только для отношений, которым назначено ограничение ацикличности или строгого порядка.

Один BFS по спискам смежности стоит `O(V + E)`, обход из каждой вершины — `O(V · (V + E))`. BFS не заменяет произвольные правила с несколькими отношениями или n-арными предикатами. Независимая сверка с прямым выводом применима только при совпадающей семантике программы.

## Z3

Общий режим делает проверки выполнимости формул первого порядка. Он не использует полунаивное замыкание или BFS для получения своих результатов. Кандидаты проверяются относительно одной и той же базы посылок. Найденное следствие не требуется добавлять как новое поколение базы.

Для языка с произвольными кванторами Z3 не гарантирует определённого ответа на любом входе. Общий бюджет анализа составляет 8 секунд, перебор ограничен 120 атомами. Противоречивая база блокирует выдачу следствий.

## Рассмотренные альтернативы

Резолюция доказывает следование от противного через получение пустой клаузы. В общем языке первого порядка процедура не является алгоритмом, гарантированно решающим каждый вход. Собственный движок резолюции в проекте не реализован.

RETE поддерживает сеть проверок условий и соединений с сохранением частичных совпадений. Он полезен для изменяющейся рабочей памяти, но требует дополнительной памяти. RETE не реализован, его скорость на данных проекта не измерялась.
